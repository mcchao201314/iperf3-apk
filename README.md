# iperf3 APK 下载

Android 版 **iperf3** 网络测速工具安装包（源码仓库私有，这里只放安装包）。

## 下载

- 最新版：[Releases](../../releases/latest)
- v1.1.0 直链：<https://github.com/mcchao201314/iperf3-apk/releases/download/v1.1.0/iperf3-release.apk>

## 功能

- 客户端 / 服务端双模式，手机可直接当 iperf3 服务端
- TCP / UDP、并发流、反向下载、双向打流、UDP 带宽目标（Mbps）
- 实时速率曲线、当前/平均/峰值、历史记录
- 安装包已用 release 密钥签名，支持 Android 7.0 及以上（arm64-v8a / armeabi-v7a / x86_64）

## 安装

1. 下载 `iperf3-release.apk`
2. 手机允许「安装未知来源应用」
3. 安装后打开即可使用

> 若系统提示「此应用不符合 16 KB 对齐要求」，请更新到最新安装包（已按 16 KB 页面对齐编译）。
